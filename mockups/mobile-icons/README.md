# Mobile icons mockup

Reference for [#467](https://github.com/Euro-Office/web-apps/issues/467): the mobile editor toolbars, Add panel and settings menu drawn with the web editor's Euro-Office icons, next to today's mobile icons. Not meant to be merged.

- `mockup-467.html`: self-contained page with the mockups, the mobile to web icon mapping and the gap list
- `mockup-*.png`: rendered images
- `python3 gen.py` regenerates the page from the sprites in `apps/*/main/resources/img/toolbar/icons.svg` and the mobile icons in `apps/common/mobile/resources/icons`
- `crops/`: crops of today's mobile UI used for the before/after
